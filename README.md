# Hydrosan (PWA)

Aplikasi analisis hidrologi tambang — bisa dipasang di HP (Android/iOS) dan berjalan offline setelah dibuka sekali.

## Pasang lewat GitHub Pages
1. Upload seluruh isi folder ini ke repo (root): `index.html`, `manifest.json`, `sw.js`, folder `icons/`.
2. Repo → Settings → Pages → Branch `main` / folder `/ (root)` → Save.
3. Buka `https://<username>.github.io/<repo>/` di HP.
4. Android (Chrome): menu ⋮ → **Install app / Tambahkan ke layar utama**. iPhone (Safari): Bagikan → **Tambah ke Layar Utama**.

## Update versi
Ganti `index.html`, lalu naikkan `VER` di `sw.js` (mis. `hydrosan-v2`) agar HP mengambil versi baru.
